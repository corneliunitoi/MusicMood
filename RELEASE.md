# 📦 MusicMood — Release & Versioning Policy

> [!IMPORTANT]
> **VERSION CEILING LOCK (v0.8.x Stability & Hardening Period):**
> Do **NOT** bump the project version past `0.8.x` (e.g., do not increment to `0.9.0` or `1.0.0`) until explicitly authorized by the project owner. The entire `v0.8.x` release series is strictly reserved for **stability, reliability, performance hardening, and bug fixes**. Any incremental updates must follow patch/minor notation within `0.8.x` (e.g. `v0.8.0a`, `v0.8.0b`, `v0.8.1`, etc.).

For the complete release management protocol, git tagging rules, and full historical changelog, see [RELEASE_MANAGEMENT.md](./RELEASE_MANAGEMENT.md).
